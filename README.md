# MTG-proxy-maker
Simple program that uses a decklist to pull images from the web and makes a printable PDF file.

## ▶️ How to Use

1. Make or download a deck from Moxfield.com. Save the text as deck.txt

2. The deck should be a simple card list, see example:

  1 Sol Ring
  1 Arcane Signet
  1 Atraxa, Praetors' Voice
  1 Command Tower

  
3. Place these in the same folder:

   - `proxy_maker.exe`
   - `deck.txt`

4. Double-click `proxy_maker.exe`

5. The program will:

   - Download all card images
   - Create a `card_images` folder
   - Generate `printable_proxies.pdf`

## 🖨️ Printing Tips

For best results:

### Paper Options

- Matte photo paper (recommended), or  
- Regular paper + sleeve + real card backing  

### Cutting

- Paper guillotine (best)
- Rotary cutter + metal ruler
- Scissors (least precise)

### Sleeving

Recommended to place proxy in front of a real card inside a sleeve.
